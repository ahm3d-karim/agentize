# Contributing

Thanks for helping!

## Pull request process

- Always run `npm run lint` and `npm run typecheck` before pushing.
- Branch names: `fix/`, `feat/`, `chore/`.
- Never commit directly to `main`.

## Gotchas

- The dev server caches aggressively — if you see stale widgets, delete `.next` and restart.
- Do not edit `src/api/legacy.js`; it is generated by an upstream tool.
- Dates are UTC everywhere except the dashboard, which expects Asia/Karachi.
